# Claude Code Haha v0.8.0

本次以界面重构为主：桌面端统一玻璃层、触感斜面、自动隐藏滚动条与消息流密度，侧边栏会话行与输入框交互重做，并接入开源模型品牌图标。本 fork 保留七套配色，以及推理折叠、草稿、排队消息、项目分组等自有能力。手机 App 升级到 0.1.6。官方更新记录见 NanmiCoder/cc-haha v0.8.0 发布说明。

## 核心功能

- **视觉基础层**：玻璃浮层改为半透明填充，在不支持模糊的引擎上统一回退为不透明底色；新增触感斜面、滚动边缘渐隐与阶梯动画，七套主题统一补齐令牌。
- **外壳与侧边栏**：桌面改为全幅画布加细边分割；会话行抽为共享卡片，项目分组与时间分组保持一致的状态、时间与快捷操作。
- **输入框与排队**：输入框改用玻璃外壳，排队消息放到卡片上方的缝式横幅；运行中按草稿是否为空切换排队与停止。
- **模型下拉停靠区**：模型列表底部可改推理强度、快速模式与执行权限，调整时不关闭面板。
- **消息流**：活动行改用 24 像素图标列，变更卡片头部在滚动时保持可见，用户气泡采用更大圆角并在相邻时收紧朝向圆角。
- **模型品牌图标**：模型选择器、供应商设置与会话统一使用开源模型与供应商标识，未知模型回退到通用芯片图标。
- **标签栏与侧边栏**：标题栏改为画布透明加底边细线，会话标签收成胶囊；侧边栏标题与搜索、视图切换、新建会话合成一行。
- **设置与用量**：设置页支持斜杠聚焦搜索，分组卡片支持内嵌标题栏；Token 用量页与分享图统一分组，分享图仍提供七套主题。
- **通知提示音**：系统通知可同时播放提示音，在「设置 → 通用 → 系统通知」下单独开关，默认开启；通知本身静音、由主进程单独发声，避免与系统声音叠加。权限确认、Computer Use 等待、Agent 回复完成、定时任务与空闲电源倒计时共用这条链路。

## 保留的 fork 能力

- 七套配色，信息色与品牌色分离，行内代码与围栏代码各有独立底色。
- 推理折叠、回合尾件、后台唤醒段折叠与变更卡片按会话缓存。
- 排队消息附件与取消回退、草稿持久化、项目分组稳定排序与无会话项目记忆。
- 设置内容搜索、Token 速度与缓存命中、历史索引持久化与空闲电源一次性动作。

## 修复

- 玻璃浮层在不支持 `backdrop-filter` 的引擎上不再让页面文字透出。
- 连续用户消息气泡在相邻时收紧朝向圆角，单独一条保持完整圆角。
- 思考块、变更卡片与结果预览的滚动边缘渐隐改为跟随滚动位置，停在首行或末行时不再遮住正文。
- 设置搜索支持 `/` 聚焦，输入框内与模态对话框打开时不抢键。
- 网关省略 `message.role` 时助手回复不再丢失，历史索引升级后自动重建以补全消息计数与标题。
- 智能体团队完成收尾后，画布依赖边停止流动，侧边栏不再一直显示运行中转圈。
- 大仓库打开文件浏览时不再卡死：工作区状态与文件树改为分页与虚拟化，超大仓库只展示截断提示。
- `/goal` 在停止时清除当前目标，求值器报错不再无限重试；第三方端点的目标求值不再因拒绝禁用思考而报 400。

## 其他

- 手机 App 0.1.6：桌面端发布后自动构建并附上新的 APK；iOS 走 TestFlight。

## 安装

桌面端在本仓库 Release 的 Assets 中下载 Windows 安装包：

- `Claude-Code-Haha-0.8.0-Windows-x64-Setup.exe`

以 `-update.zip` 结尾的文件与 `latest.yml` 是自动更新使用的，不需要手动下载。

手机 App 需要桌面端 v0.8.0 或更新版本：

- Android：下载 Assets 中的 `cc-haha-mobile-0.1.6-*.apk`。
- iPhone / iPad：通过 TestFlight 加入测试，新构建审核通过后公开链接会更新到 0.1.6。
